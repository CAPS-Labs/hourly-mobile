Hourly is a time-tracking and reporting app for volunteer organizations. This repo contains the source code for Hourly's mobile client, written in Typescript and using the React Native framework.

# Tech Stack

Hourly is written in [Typescript](https://www.typescriptlang.org/). It uses the [React Native](https://reactnative.dev/) framework for mobile development, which is based off of the [React](https://react.dev/) framework. Building and templating is handled by [Expo](https://docs.expo.dev/).
